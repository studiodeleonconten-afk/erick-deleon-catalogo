# Erick De León — Catálogo Fotográfico

## Cómo publicar en Netlify (1 minuto)

1. Descarga el ZIP completo del chat: `erick-deleon-catalog.zip`
2. Entra a **https://app.netlify.com/drop**
3. Arrastra la carpeta `erick-deleon-catalog` (o el ZIP descomprimido)
4. Netlify te da un link público al instante (ej. `https://random-name-123.netlify.app`)

No necesitas cuenta para el primer deploy. Luego puedes reclamar el sitio y poner un dominio propio.
